# MacSCP

A native macOS file transfer client modelled 1:1 on WinSCP's interface and behaviour.
It imports your existing `WinSCP.ini` sites, including saved passwords.

> Working name. The product name, bundle id and version live in [`branding.env`](branding.env).
> "WinSCP" is a trademark of its authors; this project is not affiliated with it and contains no WinSCP code.

## Build and run

Needs macOS 13+, Swift 5.9+ (Command Line Tools are enough, Xcode is optional) and Homebrew `libssh2` + `openssl@4`. They are linked statically, so the built app runs on Macs without Homebrew.

```bash
scripts/build_app.sh --install
```

This builds `build/MacSCP.app`, signs it ad hoc and copies it to `~/Applications`.

```bash
scripts/test.sh
```

Runs the unit tests. For the SSH integration tests, first start a throwaway local SSH server (key login only, `127.0.0.1:2222`):

```bash
scripts/test_sshd.sh start
```

For the FTP/FTPS tests, start a throwaway pyftpdlib server (`127.0.0.1:2121`, user `tester` / `secret`). The first run needs network access to install it into a private venv:

```bash
scripts/test_ftpd.sh start
```

Without these servers, the integration tests are skipped.

## Importing WinSCP.ini

1. On Windows, find the file: WinSCP → Tools → Preferences → Storage. If the configuration is in the registry, choose **Export/backup configuration** to get an `.ini`.
2. Copy it to the Mac.
3. In MacSCP's Login window: **Tools ▾ → Import Sites from WinSCP.ini…**

What is imported, per site: folder path, protocol (SFTP/SCP/FTP; WebDAV and S3 are listed but cannot connect yet), host, port, user, password, FTP encryption and passive mode, private key path, remote directory, note, colour.

What needs attention afterwards (marked ⚠︎ in the site tree):
- **Windows paths.** Local directories like `C:\…` are dropped. Key files are looked up by file name in `~/.ssh`; if missing, pick them in **Advanced…**.
- **Workspaces** import as workspaces: open them from the Login tree (Login opens every session as a tab). Save your own with Session → Save Workspace (⇧⌘S).
- **Master password:** you are asked for it and it is checked against the file's verifier, then all passwords are decrypted. Skip it to import the sites without passwords.

After importing, delete the `.ini`. WinSCP only obfuscates its passwords, so anyone with the file can read them.

A fake sample lives in [`fixtures/winscp.sample.ini`](fixtures/winscp.sample.ini), generated by [`tools/make_fake_ini.py`](tools/make_fake_ini.py).

## Preferences (⌘,)

Organised like WinSCP's Preferences dialog:

| Section | Settings |
|---|---|
| Environment | Theme (follow system / light / dark), interface (Commander / Explorer) |
| Confirmations | Delete, overwrite, quit with queued transfers, close session |
| Panels | Hidden files (⇧⌘.), size format, double-click action (open / edit / copy), local delete to Trash, synchronized browsing. Folders always sort first. |
| Editors | F4 opens **Sublime Text** (4, 3 or 2), falling back to **TextEdit**. A custom editor app can be chosen. |
| Transfer | Preserve timestamp and permissions, resume with `.filepart` and threshold, speed limit, exclude mask (`*.tmp; .git/`), background by default |
| Endurance | Auto-reconnect: on/off, attempts, delay |
| Network | Connection timeout, keepalive interval, IPv4/IPv6 |
| Logging | Session log (default `~/Library/Logs/MacSCP/session.log`). Paths and errors only, never passwords. |
| Security | Clear cached host keys |

Per site (Advanced…): SSH compression and a timezone offset, on top of the key, directories, SCP fallback and passive mode. Importing a `WinSCP.ini` also brings over the WinSCP preferences it recognises (confirmations, hidden files, double-click action, preserve time and rights, resume, speed limit) and per-site Compression / TimeDifference.

## Appearance

The app follows macOS light/dark mode by default and switches live. Preferences → Environment can force Light or Dark.

## Commander window

| Key | Command |
|---|---|
| F2 | Rename |
| F4 | Edit (remote files: download, open in default editor, upload on every save) |
| F5 / F6 | Copy / Move to the other panel |
| F7 | Create directory |
| F8 | Delete (local items go to the Trash) |
| F9 | Properties and permissions |
| Tab | Switch panel |
| Return / Backspace | Open / parent directory |

On a Mac keyboard, hold **fn** for the F-keys, or use the **Files** menu. Drag files between panels or in from Finder.

**Synchronize** (toolbar or ⌥⌘S) compares the local and remote folders recursively by modification time, size, or both. Directions:
- **Both:** the newer side wins.
- **Remote:** make remote match local.
- **Local:** make local match remote.

*Delete files* turns Remote/Local into a mirror. The checklist preview lets you untick single changes. A file on one side and a folder of the same name on the other is reported as a conflict and never touched. The exclude mask from Preferences applies. FTP gets a 60 s time tolerance because FTP servers list times in minutes.

**Keep Remote Directory up to Date** (⌥⌘U) watches a local folder with FSEvents and uploads changes about 1 s after they settle. It can also delete remote files that were removed locally.

**Find Files** (⇧⌘F) searches the remote tree by mask (`*.log; report*`) on its own connection, so the panels stay usable. Double-click a result to show it in the remote panel.

**Synchronized browsing** (⇧⌘B or toolbar) mirrors "open folder" and "go up" from one panel in the other.

**Explorer interface** (Preferences → Environment): remote panel only, with Finder as the local side. Drag remote files or folders straight into Finder; they download where you drop them.

**Lost connections** reconnect automatically: up to 3 attempts, 5 s apart, configurable under Preferences → Endurance. The interrupted operation then runs again. Queued transfers resume from their `.filepart`. The status bar shows reconnect progress.

**Background transfers:** tick *Transfer in background* in the Copy/Move dialog. The item goes to the queue under the panels (toolbar **Queue** shows or hides it). Each tab's queue uses its own second connection, opened with the answers you already gave (password, key passphrase, host key), so browsing stays responsive. Right-click a queue item to cancel it or clear finished ones.

Transfers over 100 KB go through a `.filepart` temp file and are renamed when complete. An interrupted download resumes from the `.filepart` on the next attempt.

## Connecting

- **Command line:** `MacSCP --open "Folder/Site name"` opens a stored site, like `winscp.exe "Site name"`.
- **Authentication order:** private key from the site settings, then ssh-agent, then keyboard-interactive and password. You are prompted if no password is stored.
- **Keys:** OpenSSH and PEM keys, encrypted or not. PuTTY `.ppk` v2 and v3 unencrypted, and v2 encrypted. Encrypted v3 `.ppk` files use Argon2; convert those with PuTTYgen → Conversions → Export OpenSSH key.
- **SCP mode** runs `ls`, `mv`, `rm`, `chmod` and `touch` on the server, so it needs a POSIX shell, like WinSCP's SCP mode. Listings use `TZ=UTC` and the most precise date format the server's `ls` supports.
- **FTP/FTPS** uses the system libcurl with macOS's trust store. Listings use MLSD, then fall back to `LIST -a` and `LIST` (Unix and Windows/IIS formats). Untrusted certificates ask *Connect Anyway / Cancel*; the answer lasts for that session only and is never saved.
- **Host keys** are checked against MacSCP's own cache, `~/.ssh/known_hosts` (read-only, hashed entries included) and keys imported from WinSCP.ini (ed25519 and RSA). An unknown key asks *Accept / Connect Once / Cancel*. A changed key shows WinSCP's "POTENTIAL SECURITY BREACH" warning with **Cancel** as the default button.

## Large directories

There is no entry limit. Folders with 20,000+ files list fully over SFTP, SCP, FTP and locally; `LargeDirectoryTests` checks this on every protocol. Rows are drawn lazily, so the table stays responsive.

## Security

- Passwords are stored in the macOS Keychain (`WhenUnlockedThisDeviceOnly`, no iCloud sync). They are never written to disk.
- Site settings live in `~/Library/Application Support/MacSCP/sites.json`, with folder mode `0700` and file mode `0600`.
- Host keys are cached in `host_keys.json` next to `sites.json`, mode `0600`.
- File names received from servers are validated before anything is written locally, so `../` and `/` cannot escape the target folder.
- New local files are created with `O_NOFOLLOW`, so a planted symlink is never followed.
- SCP shell arguments are always single-quoted.
- FTP commands containing CR, LF or NUL are refused, so file names cannot inject extra FTP commands.
- **Move** never deletes a source that was partly skipped at an overwrite prompt.
- A downloaded file never replaces a local folder of the same name.
- Symlinked folders are followed only when you select them directly, so link loops can't run away.
- F4-edit copies live in a `0700` folder in Caches. They are deleted on quit, and any leftovers are removed at the next launch.
- The app is signed with the hardened runtime.

## Known limitations

- **Not yet built:** WebDAV, S3.
- **Master password** decryption follows WinSCP's AES format (WinZip-AES / fcrypt). It is verified against an independent Python implementation, not yet against a file from WinSCP itself. Every password is MAC-checked, so it either decrypts correctly or is reported as failed.
- **FTPS.** An accepted untrusted certificate is not pinned; you are asked again on every connect.
- **Keyboard.** F-keys need **fn** on Mac keyboards (or use the Files menu).
