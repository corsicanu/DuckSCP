# DuckSCP 1.0.0

The first public release: a native macOS file transfer client with WinSCP's two-panel workflow. It imports your WinSCP sites, passwords, workspaces and preferences.

## Download

| File | For |
|---|---|
| `DuckSCP-1.0.0-macOS-arm64.dmg` | Install: open, drag DuckSCP to Applications |
| `DuckSCP-1.0.0-macOS-arm64.zip` | Same app, zipped |

Apple Silicon. Built and tested on macOS 27. The minimum it declares is macOS 13, but versions before 27 are untested.

**First launch:** DuckSCP is signed but not notarized by Apple, so macOS blocks the first open. Use one of these:
- Control-click DuckSCP in Applications → **Open** → **Open**.
- Or open it once, then go to **System Settings → Privacy & Security → Open Anyway**.

## What's in it

- **Protocols:** SFTP, SCP, FTP/FTPS, WebDAV and Amazon S3 (or S3-compatible).
- **WinSCP.ini import:** sites, passwords (including master-password protected), workspaces, preferences and host keys.
- **Commander window:**
  - two panels, session tabs, breadcrumb paths
  - F-key commands
  - Synchronize and Keep Remote Directory up to Date
  - Find Files
  - synchronized browsing
  - Explorer mode
- **Edit (F4):** opens remote files in Sublime Text (or TextEdit). Every save is uploaded and listed in the transfer queue.
- **Transfers:**
  - background queue on its own connection
  - resume with `.filepart` files
  - auto-reconnect, speed limit, exclude masks
- **Security:**
  - passwords in the Keychain
  - host-key and certificate pinning
  - SOCKS and HTTP proxies
  - no limit on the number of files in a folder
- **Look:** follows macOS light/dark mode and your accent color, or a custom one.
