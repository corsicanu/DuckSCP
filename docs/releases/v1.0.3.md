# DuckSCP 1.0.3

A bug fix, plus everything from 1.0.2 (which was withdrawn).

## Fixed in 1.0.3
- **Browsing one panel moved the other.** Synchronized browsing could get switched on by one click on the toolbar button (or ⇧⌘B) without any visible sign, and it stayed on for every session. It's now per session and off on every new connection, like WinSCP. When it's on, you see it: the toolbar says *Sync Browsing: On*, the status bar shows a badge, and the Commands menu item has a checkmark. If it was stuck on, updating turns it off.

## From 1.0.2
- **No more Keychain prompts after updates.** DuckSCP is now signed with a stable certificate, so macOS treats each new version as the same app.
  - **Coming from 1.0.0/1.0.1**, macOS asks for your login keychain password **one last time**. That's your Mac login password; click **Always Allow**.
- **Updates must come from the same signer.** The built-in updater refuses packages signed by a different certificate, on top of the checksum, bundle id and version checks.
- **Sites reopen where you left them.** The last remote and local folders are remembered per site. Turn it off per site under Advanced → *Remember last used directory*.
- **The ⚠︎ import marker clears** after the site's first successful connection, on Save, or via Manage → Clear Warnings.
