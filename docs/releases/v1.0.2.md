# DuckSCP 1.0.2

No more Keychain prompts after updates, and sites that remember where you left them.

## Fixed
- **Keychain prompts after updating.** Earlier versions were signed ad hoc, so macOS treated every new version as a different app and asked for your login keychain password. 1.0.2 is signed with a stable certificate, so future updates keep access to your saved passwords without asking.
  - **Coming from 1.0.0/1.0.1**, macOS asks one last time. Enter your Mac login password and click **Always Allow**.
- **Sites opened in the imported folder every time.** Sites now remember the last remote and local folder you used and reopen there. It's on by default; turn it off per site under Advanced → *Remember last used directory*.
- **The ⚠︎ import marker never went away.** It now clears after the site's first successful connection, when you press Save, or via Manage → Clear Warnings.

## Security
- **Updates must come from the same signer.** The built-in updater refuses a package signed by a different certificate than your installed copy, on top of the existing checksum, bundle id and version checks.
