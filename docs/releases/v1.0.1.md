# DuckSCP 1.0.1

Three improvements from real use: a WinSCP-style drop prompt, built-in updates and Finder-style renaming.

## New

- **Drop prompt with history.** Dropping files onto a panel, from Finder or from the other panel, asks where to put them, like WinSCP:
  - **Suggested:** the folder you dropped on, or the open folder.
  - **History:** recent target folders, shared by all sites.
  - **Type:** any other path, or choose a local folder for downloads.

  F5/F6 use the same dialog.
- **Updates.** DuckSCP checks GitHub Releases when it starts, or from **DuckSCP → Check for Updates…**. Pre-releases are offered with a warning that they may contain bugs or untested features. **Update** downloads the package, verifies it, then replaces the app and reopens it. It checks the SHA-256 checksum, the code signature, the bundle id and the version.
- **Rename like Finder.** Click a selected file's name again and it becomes editable, with the base name selected. F2 does the same. Return saves, Escape cancels.

Apple Silicon, tested on macOS 27. First launch of a downloaded copy: Control-click DuckSCP → **Open** → **Open**. DuckSCP is signed but not notarized.

Updating from 1.0.0: 1.0.0 has no updater yet, so install 1.0.1 from the DMG once. From 1.0.1 on, updates install themselves.
